## 🚀 使用路径

1. **从 `login.html` 开始** — 选择角色 → 输入账号密码 → 登录进入工作台
2. 工作台顶栏 6 项导航切换板块;A 板块各文件侧栏含"物业监管·板块导航"(A-1~A-6)
3. 移动端 3 文件独立打开(414px 手机视图),底部 TabBar 真实切换

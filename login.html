Q1忘记密码怎么办? ›
点击登录表单右下角的「忘记密码?」,进入 系统管理 → 修改密码 / 安全 页面,通过绑定手机号短信验证后重置;也可联系本单位管理员在「系统管理 → 账号管理」中重置。
前往修改密码 →
Q2收不到短信验证码? ›
① 确认手机号与账号绑定一致且信号正常;② 检查短信拦截 / 骚扰拦截设置;③ 同一手机号每日限发 10 条,超出后次日 0 点恢复;④ 仍收不到可使用「扫码登录」或联系管理员检查「系统管理 → 短信频次配置」。
Q3账号被锁定了如何处理? ›
密码连续输错 5 次 系统将锁定账号 30 分钟(安全策略),到点自动解锁;如需立即解锁,请联系管理员在「系统管理 → 登录日志」中核查并手动解锁。
Q4物业企业 / 主管部门如何使用 UKey 登录? ›
涉及备案审批、资金拨付等高权限操作的角色需插入 数字证书 UKey:在账号密码验证通过后,系统会提示插入 UKey 进行二次签名。证书申领与驱动安装见「系统管理 → 数字证书 / UKey」。
前往数字证书管理 →
Q5支持哪些浏览器?移动端如何访问? ›
桌面端推荐 Chrome / Edge 100+(分辨率 1440×900 及以上),兼容 360 极速模式;移动端业主请通过「秦务员」APP 或微信小程序进入,物业企业与主管部门可使用下方对应移动端入口。
Q6登录后可以切换角色视角吗? ›
可以。进入工作台后,点击顶栏右侧「切换角色视角」,数据与待办将按新角色权限自动重算;省级 / 市级 / 县区级主管之间切换不改变账号,仅改变数据可见范围。
Q7提示"异地登录 / 非常用设备登录"怎么办? ›
系统检测到登录 IP 或设备指纹与常用环境不一致时会触发保护:首次需完成短信验证码二次确认;若确认非本人操作,请立即修改密码并在「系统管理 → 登录日志」中核查异常记录,必要时联系管理员冻结账号。
Q8可以多端 / 多浏览器同时登录吗? ›
同一账号支持 桌面端 + 移动端各 1 个会话 同时在线(共 2 个);同端重复登录会踢出较早会话并推送站内消息提醒。涉及 UKey 签名的审批操作同一时刻仅允许单会话,防止双签冲突。
Q9我的数据安全吗?系统如何保护隐私? ›
本系统通过 等保三级 测评:传输层采用国密 SM2/SM4 加密;业主手机号、身份证号等敏感字段在展示层默认脱敏;全部操作(登录、查询、导出、借阅)均写入操作审计日志并支持区块链存证;档案库启用四性检测(真实 / 完整 / 可用 / 安全)。
Q10业主如何在移动端注册并绑定房屋? ›
业主下载「秦务员」APP 并实名注册后,进入「物业服务」专区 → 「我的房屋」→「绑定房屋」,选择小区 / 楼栋 / 单元 / 户室并上传产权证明,物业企业确认后即完成绑定,方可参与投票表决、报修与投诉。
Q11打开综合大屏提示"无访问权限"? ›
综合大屏(省级住建专题)默认仅对 省级主管 及授权角色开放。市 / 县区级主管可访问本级专题视图;如业务确需,请由单位管理员在「系统管理 → 个人设置 → 角色权限」中申请开通,并经上级主管部门审批。
Q12登录页可以记住哪些信息?公共电脑安全吗? ›
勾选「记住登录」后,本机浏览器仅记住 账号名(不保存密码),下次登录仍需输入密码与短信验证码;验证码每 8 小时免重复发送一次。公共电脑请勿勾选,并建议使用浏览器无痕模式,用毕务必点击「退出登录」。
Q13业主大会短信委托与登录账号是什么关系? ›
业主大会发起后,系统向已绑定房屋的业主推送 短信委托链接:业主点击链接即可在移动端完成身份核验并提交表决意见,无需单独注册登录;表决结果实时汇总至「业主决策 → 物业投票」监控大屏,全程留痕可回溯。

```
[侧栏]
├── 板块导航分组(A 板块文件显示 A-1~A-6 六项;当前子模块高亮,其余跨文件链接)
```

各板块文件的"板块导航"内容:
- **A 板块 4 个文件**(a1/a2/a3/a4to6)侧栏顶部插入"物业监管"分组:A-1 物业事项备案(cur 于 a1)/ A-2 维修资金 / A-3 数据监测 / A-4 评价监管 / A-5 承接查验 / A-6 进入退出(后四项都指向 web_a4to6 的对应锚点)

## 二、系统交互流程(实际系统)

```
打开系统
  ↓
login.html(独立登录页)
  ├─ 角色选择(省级/市级/县区级/街道社区/物业企业/业委会/业主)
  ├─ 账号 + 密码 + 短信验证码(双因素)
  ├─ 验证 → 进入工作台
  ↓
web_main.html(工作台/主页)
  ├─ 顶栏 6 项导航
  ├─ KPI / 模块入口 / 待办 / 消息
  ↓
各板块文件(a1/a2/a3/a4to6/b/c/d/z)
  ├─ 顶栏同款 6 项导航(当前板块高亮)
  ├─ 侧栏:板块导航 + 本模块页面
  └─ 页面内 switchPage + hash 直达
```

- login.html 为系统**默认入口**(打开系统先见登录页)
- 顶栏头像下拉含"退出登录"→ 回 login.html
- 移动端入口:web_main 端类型切换区 + login 页底部的移动端入口
